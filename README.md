> Современное интерактивное веб-приложение на русском языке для эффективного изучения, тестирования и тренировки знаний столиц, географического положения. а также и соседей всех стран мира.

## 📸 Скриншоты и возможности

| Режим викторины с контурной картой | Режим исследования (Инспектор мира) |
|:---:|:---:|
| Интерактивный вопрос, выбор из вариантов или ввод текста, указание страны на карте | Мгновенный показ столицы со стрелкой, соседей 1-го и 2-го круга и факта |

## ✨ Ключевые особенности

### 1. 100% покрытие стран мира (177 государств)
В приложении представлены **все 177 суверенных государств**, присутствующих в векторной топологии `world-atlas (110m)`. Для каждого государства указаны:
- Название на русском и английском языках;
- Официальная столица и её географические координаты;
- Эмодзи-флаг;
- Регион (Европа, Азия, Африка, Америка, Океания);
- Население и интересный географический факт;
- Географические границы и граф смежности (соседние государства).

### 2. Разнообразные режимы тренировки и обучения
* 🎯 **Прямой режим («Столица → Страна»)**: дается столица — нужно выбрать или написать название страны.
* 🔄 **Обратный режим («Страна → Столица»)**: дается название страны и флаг — нужно определить её столицу.
* 🧭 **Режим Исследования (Инспектор мира)**: интерактивная карта для свободного изучения. Наведите или нажмите на любую страну — карта выделит её контур, приблизит камеру, покажет столицу с радарной точкой и стрелкой, выделит соседние государства 1-го и 2-го порядка полутонами и выведет увлекательный факт.
* 📚 **Режим Обучения (Flashcards)**: пошаговое прохождение стран по регионам. Интерактивные карточки с переворотом, показом на карте и статусами прогресса: *«Изучаю»*, *«Знаю»*, *«Мастер»*.
* 🗺️ **Географический Атлас**: каталог всех стран с поиском, сортировкой и фильтром по частям света.

### 3. Интерактивная векторная карта D3-Geo (Natural Earth 1)
* **Топологическая точность**: рендеринг реальных границ без внешних тяжёлых картографических сервисов — 100% автономно и офлайн.
* **Режим контурного поиска**: после верного ответа на вопрос приложение просит найти и указать страну на контурной карте (все надписи скрыты до момента попытки).
* **Стрелка и точное местоположение столицы**: после ответа страна укрупняется, а её столица отмечается пульсирующей точкой, радарным кольцом, стрелкой-указателем и контрастной табличкой.
* **Соседи 1-го и 2-го круга**: на карте автоматически подсвечиваются прямые соседи (сине-стальной полутон) и соседи соседей (графитовый полутон) с подписями прямо на карте.
* **Полная адаптивность для мобильных**: специальный алгоритм масштабирования шрифтов и маркеров гарантирует кристальную чёткость и читаемость на смартфонах и планшетах. Поддерживается сенсорное панорамирование (touch pan).
* **Защита от случайного зума**: колесо мыши не сбивает масштаб при прокрутке страницы; масштабирование управляется экранными кнопками «+ / −» и центрированием по клику.

### 4. Глубокая аналитика и персональные рекомендации
* 📊 **Аналитика по частям света**: расчёт точности (%) по Европе, Азии, Африке, Америке и Океании.
* ⚠️ **Выявление слабых мест**: приложение определяет отстающий регион и выводит кнопку *«Подтянуть регион»*.
* 📉 **Рейтинг пар**: алгоритм отслеживает пары «страна — столица» с наихудшим процентом правильных ответов и предлагает целенаправленную тренировку по проблемным парам.
* 🔥 **Статистика сессий**: серии побед (streak), количество правильных и ошибочных ответов, общий процент успеваемости.

### 5. Гибкие настройки
* Формат ответа: **выбор из 3 вариантов**, **выбор из 5 вариантов** или **ручной ввод с клавиатуры**.
* Опция отключения поиска на контурной карте (для быстрой текстовой викторины).
* Звуковые эффекты победы, ошибки и кликов (синтезируются через Web Audio API, без загрузки MP3-файлов).

## 🚀 Быстрый старт

### Требования
- [Node.js](https://nodejs.org/) версии 18 или выше
- Менеджер пакетов `npm` или `pnpm`

### 1. Клонирование репозитория
```bash
git clone https://github.com/ВАШ_ЛОГИН/terraquiz1.git
cd terraquiz1
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск локального сервера разработки
```bash
npm run dev
```
После запуска откройте браузер по адресу: `http://localhost:3000` (или адресу, указанному в консоли).

### 4. Проверка типов и линтинг
```bash
npm run lint
```

### 5. Сборка для продакшена
```bash
npm run build
```
Готовая сборка будет находиться в директории `dist/`.

## 🌐 Деплой на GitHub Pages

В репозитории уже настроен базовый путь в `vite.config.ts`:
```ts
base: process.env.NODE_ENV === 'production' ? '/terraquiz1/' : '/',
```

### Способ 1: Деплой через ветку `gh-pages` (пакет `gh-pages`)

1. Установите утилиту `gh-pages` (если не установлена):
   ```bash
   npm install -D gh-pages
   ```
2. Добавьте скрипты в `package.json`:
   ```json
   "scripts": {
     "predeploy": "npm run build",
     "deploy": "gh-pages -d dist"
   }
   ```
3. Выполните команду деплоя:
   ```bash
   npm run deploy
   ```
4. В настройках репозитория на GitHub перейдите в **Settings → Pages** и выберите ветку `gh-pages` и папку `/(root)`.

### Способ 2: Деплой через GitHub Actions (рекомендуется)

Создайте файл `.github/workflows/deploy.yml`:
```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [ main ]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: "pages"
  cancel-in-progress: true

jobs:
  build-and-deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'

      - name: Install dependencies
        run: npm ci

      - name: Build project
        run: npm run build

      - name: Setup Pages
        uses: actions/configure-pages@v4

      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: './dist'

      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

После пуша в ветку `main` приложение будет автоматически собрано и опубликовано по адресу:
`https://ВАШ_ЛОГИН.github.io/terraquiz1/`
